# 仿真逻辑说明

本文档说明水电站数字孪生平台的仿真模型、公式与数据流。实现代码位于 `src/sim/Simulation.js`，常量集中在 `src/config/assets.js` 的 `SIM` 对象。

## 1. 坐标与符号约定

- 坝轴沿 X 方向，水流沿 +Z（上游 −Z → 下游 +Z），Y 为高程（m）；
- `H_u` 上游水位，`H_d` 下游水位，净水头 `H = H_u − H_d`；
- 时间步长 `dt` 由渲染循环提供，并钳制在 50 ms 以内。

## 2. 水力模型

### 2.1 发电流量

单机过流按导叶开度与水头修正：

```
q_unit = guideVane × Q_max × √(H / H_rated)        （检修工况强制为 0）
Q_gen  = q_unit × 机组台数(3)
```

其中 `Q_max = 280 m³/s`，`H_rated = 42 m`。`√(H/H_rated)` 反映低水头下过流能力下降。

### 2.2 机组出力

```
P = ρ · g · Q_gen · H · η / 10⁶   (MW)
```

`ρ = 1000 kg/m³`，`g = 9.81 m/s²`，综合效率 `η = 0.92`。额定工况（H=42 m、导叶 0.8）下全厂出力约 300 MW。

### 2.3 泄洪流量

溢流表孔按宽顶堰自由出流近似，逐孔累加：

```
e       = gateOpen[i] × H_hole          （孔口开启高度，H_hole = 8 m）
H0      = max(H_u − 47, 0)              （堰上水头，堰顶高程 47 m）
Q_spill = Σ C · B · e · √(2g(H0 − e/2))
```

流量系数 `C = 0.48`，单孔净宽 `B = 14 m`，共 5 孔。

### 2.4 水库水位动态

水量平衡离散积分：

```
dH_u/dt = (Q_in − Q_gen − Q_spill) / A_reservoir
```

入库流量 `Q_in = 900 m³/s`，库面面积 `A = 2×10⁷ m²`。水位被钳制在 `[30, 55] m`（死水位 ~ 坝顶）。泄洪工况下可观察到上游水位持续回落。

## 3. 机械联动

### 3.1 机组转速

一阶惯性环节逼近目标转速：

```
n_target = 0                          （检修工况）
n_target = n_rated × (0.55 + 0.45 × min(1.4·P/P_rated, 1))   （发电/泄洪）
n ← n + (n_target − n) × min(0.8·dt, 1)
```

`n_rated = 187.5 r/min`。转速驱动三维转子角速度 `ω = n·π/30 (rad/s)`。

### 3.2 闸门升降

每扇闸门位置按开度平滑提升（最大 8 m）：

```
y_target = y_base + gateOpen[i] × 8
y ← y + (y_target − y) × min(3·dt, 1)
```

## 4. 工况逻辑

| 工况 | 导叶开度 | 表孔闸门 | 机组状态 |
|------|---------|---------|---------|
| 发电 generation | 0.80 | 全关 | 带负荷运行 |
| 泄洪 flood | 0.35 | 五孔 0.70 | 减负荷运行 |
| 检修 maintenance | 0 | 全关 | 停机惰走，转速→0 |

工况切换只设置目标量，所有物理量经平滑过渡，避免画面跳变。

## 5. 水流粒子

三类发射器，发射强度与仿真量联动：

| 发射器 | 位置 | 强度来源 |
|--------|------|---------|
| 溢流孔 ×5 | 堰顶各孔口 | 对应闸门开度 × 堰上水头系数 |
| 泄洪深孔 ×2 | 坝身出口 | 泄洪工况激活 |
| 尾水 ×1 | 厂房尾水出口 | `Q_gen / 900` |

粒子为重力抛物线运动，固定容量 4000 的对象池循环复用，单次 draw call 渲染。

## 6. 数据流

```
用户输入(面板) ──→ Simulation.state ──→ update(dt) 水力/机械计算
                                            │
        ┌───────────────────────────────────┼────────────────────────┐
        ▼                                   ▼                        ▼
  场景联动(main.js)                   面板监视(Panel)           粒子发射强度
  闸门y / 转子ω / 水面高程            水头/流量/出力/转速        spill/outlet/tailrace
```

## 7. 可扩展方向

- 接入真实 SCADA 数据：将 `Simulation` 的状态量替换为 WebSocket 推送值；
- 库容曲线：用实际 `V-H` 曲线替换定常库面面积假设；
- 耗水率/振动区等机组特性曲线插值；
- 洪水过程线：将 `INFLOW` 改为时间序列驱动。
